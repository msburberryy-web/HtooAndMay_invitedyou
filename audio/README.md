# Audio Files

Place these two files in this folder:

| Filename | Description | Duration |
|----------|-------------|----------|
| `piano.mp3` | Soft ambient piano — loops seamlessly | 2–4 min |
| `birds.mp3` | Gentle birds / nature ambience (Japanese forest sounds) | 2–4 min |

## Where to download (free, no attribution required)

**Piano ambient:**
- https://pixabay.com/music/search/piano%20ambient/ — search "peaceful piano" or "soft piano wedding"
- Recommended: "Emotional Piano" or "Gentle Piano" by Pixabay artists

**Birds / nature ambience:**
- https://pixabay.com/sound-effects/search/birds/ — search "Japanese birds", "forest birds", "morning birds"
- Or search "nature ambience Japan" for forest + birds combo

## How it plays

- Birds fade in first (0.3 volume) — 1.2 seconds after the envelope opens
- Piano fades in next (0.55 volume) — 2.4 seconds after envelope opens
- The ♪ button (bottom-right corner) lets guests toggle music on/off at any time
- Both tracks loop indefinitely
