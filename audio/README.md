# Audio Files

Clicking a vinyl record in the "chapters of our story" section switches the background music to that memory's own track. Drop MP3 files in this folder using these exact names, and the site will pick them up automatically — no code changes needed:

- **`piano.mp3`** — general background music, plays by default and whenever no record is selected
- **`rec-first-meet.mp3`** — plays when the "First meet" record is clicked
- **`rec-first-date.mp3`** — "First date"
- **`rec-first-trip.mp3`** — "First trip"
- **`rec-meeting-family.mp3`** — "Meeting family"
- **`rec-proposal.mp3`** — "The proposal"
- **`rec-public-announce.mp3`** — "Going public"
- **`rec-nikkah.mp3`** — "Nikkah"
- **`rec-side-wedding.mp3`** — "The wedding"

Any file you don't provide yet is fine — the site falls back to a soft synthesized placeholder melody (a different little tune per record) until you add the real track, so nothing breaks in the meantime.

## Where to download (free, royalty-free)

- [Pixabay – piano ambience search](https://pixabay.com/music/search/piano%20ambient/)
- [Pixabay – music search](https://pixabay.com/music/)

Pick something soft and looping for each. The site starts audio on the first user interaction (browser autoplay policy) — clicking a record or the music button both count.
