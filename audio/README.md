# Audio Files

Place the following file in this directory:

- **`piano.mp3`** — background piano music (loops continuously)

The site also supports birds ambience as a second layer. If you have `birds.mp3`, add it too and update the `<audio id="bgm">` element to use it (or add a second `<audio>` element in `index.html`).

## Where to download (free, royalty-free)

- [Pixabay – piano ambience search](https://pixabay.com/music/search/piano%20ambient/)
- [Pixabay – birds nature sounds](https://pixabay.com/sound-effects/search/birds/)

Pick something soft and looping. The site starts music on the first user interaction (browser autoplay policy).
